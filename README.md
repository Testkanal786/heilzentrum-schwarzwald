# Heilzentrum Schwarzwald e.V.

Statische Vereinswebsite (HTML + CSS, ohne Build-Schritt), veröffentlicht über GitHub Pages.

- `index.html` – Startseite: Verein, Tätigkeit, Wirkstätte Tunau, Mitmachen/Spenden, Kontakt
- `impressum.html` – Impressum nach § 5 DDG
- `datenschutz.html` – Datenschutzerklärung
- `style.css` – Gestaltung (hell/dunkel)

Änderungen: Datei bearbeiten, committen – GitHub Pages aktualisiert die Seite nach etwa einer Minute.
